# Data Migration Tool

Welcome to the documentation for the **M3 Data Migration Platform**.

The Data Migration Tool is used to transform legacy data into formats required for migration into Infor M3.

## Main Areas

The application is organized into:

- Configuration
- Run Migration
- Rules
- Administration
- Utilities
- Troubleshooting

## Getting Started

If this is your first time using the tool, start with the [Getting Started](getting-started/overview.md) section.
